2nd year BTech student. I build things that have a reason to exist — sometimes that reason is "I wanted to understand this dataset," sometimes it's "I wanted to see if this idea could look good on screen." Not locked into one lane yet, and not pretending to be.

**Currently:** working through data analysis / ML fundamentals, and picking up frontend/animation work on the side to stay sharp on building UI that doesn't feel generic.

### Projects worth a look

**[netflix-customer-churn-analysis](https://github.com/yuva-keerthi-n/netflix-customer-churn-analysis)**
Predicting churn from subscriber behavior data — the point was learning to go from raw data to a defensible conclusion, not just running a model.

**[saas-metrics-dashboard](https://github.com/yuva-keerthi-n/saas-metrics-dashboard)**
Built to answer a real question: which SaaS metrics actually matter and how do you compute them correctly (MRR, churn, LTV) instead of eyeballing them.

**[api-data-pipeline](https://github.com/yuva-keerthi-n/api-data-pipeline)**
A pipeline for pulling, cleaning, and structuring data from external APIs — the unglamorous plumbing work that most tutorials skip.

**[groweasy-csv-importer](https://github.com/yuva-keerthi-n/groweasy-csv-importer)**
A TypeScript tool for importing and validating messy CSVs. Built because manual CSV cleanup is a solved problem that people keep resolving by hand.

**[ocean-depths](https://github.com/yuva-keerthi-n/ocean-depths)**
A scroll-driven storytelling site with GSAP — pure creative/technical exercise in cinematic transitions and scroll-based animation.
